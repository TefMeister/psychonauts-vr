# psychonauts-vr

VR support mod for the original 2005 **Psychonauts** (Double Fine) — a DirectX 9, custom-engine game with no existing VR modding framework.

**Status: early development, not yet playable.** This repo will hold actual working releases as they become available. For development history and raw material, see [psychonauts-vr-dev-archive](https://github.com/TefMeister/psychonauts-vr-dev-archive). For field notes and technical write-ups, see [psychonauts-vr-modding-notes](https://github.com/TefMeister/psychonauts-vr-modding-notes).
